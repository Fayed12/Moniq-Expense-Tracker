# Moniq — Full Database Structure (Firestore)

All data is user-scoped. The root path for all user data is `/users/{uid}/`.
No user can read or write another user's data — enforced by Firestore Security Rules.

---

## Collection Map

```
/users/{uid}
    /accounts/{accountId}
    /categories/{categoryId}
    /transactions/{transactionId}
    /budgets/{budgetId}
    /goals/{goalId}
    /recurringRules/{ruleId}
    /notifications/{notificationId}
```

---

## 1. `/users/{uid}` — User Profile Document

**Document ID:** Firebase Auth UID (auto, same as auth uid)

```js
{
  // Identity
  uid:                  string,           // same as document ID
  displayName:          string,           // "Ahmed Hassan"
  email:                string,           // "ahmed@example.com"
  photoURL:             string | null,    // Firebase Storage URL or Google photo

  // Preferences
  currency:             string,           // ISO 4217 — "USD", "EGP", "EUR"
  locale:               string,           // "en-US", "ar-EG"
  dateFormat:           string,           // "DD/MM/YYYY" | "MM/DD/YYYY" | "YYYY-MM-DD"
  theme:                string,           // "light" | "dark" | "system"
  accentColor:          string,           // hex — user-chosen accent within palette

  // App state
  onboardingCompleted:  boolean,          // false → redirect to onboarding wizard
  monthlyBudgetLimit:   number | null,    // overall soft limit in user currency
  defaultAccountId:     string | null,    // pre-selected on Add Transaction form

  // Notifications config
  notifyBudgetAlert:    boolean,          // true
  notifyGoalReached:    boolean,          // true
  notifyRecurringDue:   boolean,          // true
  notifyWeeklyDigest:   boolean,          // false

  // Metadata
  createdAt:            Timestamp,
  updatedAt:            Timestamp,
  lastActiveAt:         Timestamp,
}
```

## 2. `/users/{uid}/accounts/{accountId}` — Financial Accounts

**Document ID:** Auto-generated by Firestore (`addDoc`)

```js
{
  id:           string,       // Firestore document ID (stored for convenience)
  name:         string,       // "Main Bank", "Wallet", "Credit Card"

  // Type controls behavior
  type:         string,       // "bank" | "cash" | "credit" | "savings"

  balance:      number,       // Current balance (updated on every transaction write)
  currency:     string,       // ISO 4217 — defaults to user currency

  // Display
  color:        string,       // hex — "#A0522D"
  icon:         string,       // react-icons key — "FaUniversity" | "FaWallet" | "FaCreditCard"

  isArchived:   boolean,      // archived accounts hidden from dropdowns, not deleted
  isDefault:    boolean,      // one account per user can be default

  // Stats (denormalized for dashboard speed)
  transactionCount: number,   // total transactions linked to this account
  totalIncome:      number,   // lifetime income into this account
  totalExpense:     number,   // lifetime expense from this account

  createdAt:    Timestamp,
  updatedAt:    Timestamp,
}
```

**Default accounts created on onboarding:**
- Cash — type: "cash" — icon: FaMoneyBillWave
- Bank Account — type: "bank" — icon: FaUniversity

## 4. `/users/{uid}/transactions/{transactionId}` — Transactions

**Document ID:** Auto-generated
**Most queried collection — all queries use composite indexes.**

```js
{
  id:             string,

  // Core fields
  title:          string,         // "Lunch at Cairo Kitchen"
  amount:         number,         // ALWAYS positive — direction from `type`
  type:           string,         // "income" | "expense" | "transfer"

  // References
  categoryId:     string,         // ref to /categories/{id}
  accountId:      string,         // source account ref
  toAccountId:    string | null,  // destination account (transfers only)

  // Date — stored as Firestore Timestamp for range queries
  date:           Timestamp,      // transaction date (user-entered, not createdAt)

  // Enrichment
  tags:           string[],       // ["work", "reimbursable", "travel"]
  note:           string | null,  // free-form note
  receiptUrl:     string | null,  // Firebase Storage download URL

  // Recurring link
  recurringRuleId: string | null, // if auto-generated by a recurring rule

  // Denormalized for list display (avoids joins on read)
  categoryName:   string,         // snapshot at write time
  categoryIcon:   string,
  categoryColor:  string,
  accountName:    string,

  createdAt:      Timestamp,
  updatedAt:      Timestamp,
}
```

**Required Firestore Composite Indexes:**
```
Collection: transactions
Index 1: date DESC (for default list view)
Index 2: type ASC, date DESC (for income/expense filter)
Index 3: categoryId ASC, date DESC (for category filter)
Index 4: accountId ASC, date DESC (for account filter)
Index 5: date ASC (for chart range queries, analytics)
```

## 5. `/users/{uid}/budgets/{budgetId}` — Monthly Budgets

**Document ID:** Recommended pattern: `{categoryId}_{YYYY-MM}` (e.g. `food_2025-01`)
This makes it easy to query and upsert without scanning.

```js
{
  id:           string,         // "{categoryId}_{YYYY-MM}"
  categoryId:   string,         // ref to /categories/{id}
  month:        string,         // "2025-01" — always YYYY-MM

  limit:        number,         // budget cap in user currency
  spent:        number,         // auto-updated on transaction write (Cloud Function or client)

  rollover:     boolean,        // if true, unused budget carries to next month
  rolloverAmount: number,       // calculated from previous month remainder

  // Denormalized
  categoryName:  string,
  categoryIcon:  string,
  categoryColor: string,

  createdAt:    Timestamp,
  updatedAt:    Timestamp,
}
```

**Note:** `spent` is recalculated client-side by summing transactions of matching
`categoryId` and `date` within the month. It is persisted back as a snapshot for
fast dashboard reads. Do NOT rely on it as a source of truth — always recalculate
from transactions for the budget page.

## 7. `/users/{uid}/recurringRules/{ruleId}` — Recurring Transaction Rules

**Document ID:** Auto-generated

```js
{
  id:           string,
  title:        string,         // "Netflix Subscription", "Monthly Salary"
  amount:       number,

  // Transaction template fields
  type:         string,         // "income" | "expense"
  categoryId:   string,
  accountId:    string,
  tags:         string[],
  note:         string | null,

  // Schedule
  frequency:    string,         // "daily" | "weekly" | "biweekly" | "monthly" | "yearly"
  startDate:    Timestamp,
  endDate:      Timestamp | null,  // null = runs indefinitely
  nextDue:      Timestamp,         // updated after each trigger

  // Behavior
  autoLog:      boolean,        // true = log silently | false = show prompt to user
  isActive:     boolean,

  // Denormalized
  categoryName:  string,
  categoryIcon:  string,
  categoryColor: string,
  accountName:   string,

  // Stats
  totalLogged:   number,        // how many times triggered
  lastLoggedAt:  Timestamp | null,

  createdAt:    Timestamp,
  updatedAt:    Timestamp,
}
```

**Client-side scheduling logic:**
On app load, query all active recurring rules where `nextDue <= now`.
For each: auto-log or show prompt → create transaction → update `nextDue` based on frequency.

## Firestore Security Rules

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Helper: user is authenticated and owns the resource
    function isOwner(uid) {
      return request.auth != null && request.auth.uid == uid;
    }

    // User profile — only owner can read/write
    match /users/{uid} {
      allow read, write: if isOwner(uid);

      // All subcollections — only the owner
      match /{subcollection}/{docId} {
        allow read, write: if isOwner(uid);

        // Goal contributions (nested subcollection)
        match /contributions/{contributionId} {
          allow read, write: if isOwner(uid);
        }
      }
    }
  }
}
```

## Data Relationships Diagram

```
users/{uid}
    │
    ├── accounts[]          ← transactions.accountId
    │                       ← transactions.toAccountId (transfers)
    │                       ← goals.linkedAccountId
    │                       ← recurringRules.accountId
    │
    ├── categories[]        ← transactions.categoryId
    │                       ← budgets.categoryId
    │                       ← recurringRules.categoryId
    │
    ├── transactions[]      ← recurringRules (generates transactions)
    │                       ← budgets.spent (aggregated from transactions)
    │
    ├── budgets[]           (per category per month)
    │
    ├── goals[]
    │   └── contributions[]
    │
    ├── recurringRules[]    → creates transactions[]
    │
    └── notifications[]
```

## Client-Side Derived Data (NOT stored in Firestore)

These are calculated in Redux selectors or utility functions from raw Firestore data.
Never store these as Firestore fields — they must always be recomputed.

| Derived Value | Source | Calculation |
|---|---|---|
| Net worth | accounts[] | sum of all account balances |
| Monthly income | transactions[] | sum where type=income AND date in month |
| Monthly expenses | transactions[] | sum where type=expense AND date in month |
| Monthly savings | above two | income − expenses |
| Savings rate | above two | (savings / income) × 100 |
| Budget spent % | transactions[] + budgets[] | (spent / limit) × 100 |
| Goal progress % | goals[] | (currentAmount / targetAmount) × 100 |
| Goal days remaining | goals[] | deadline − today |
| Category total (month) | transactions[] | sum by categoryId in month |
| Account balance delta | transactions[] | balance change over period |

## Indexing Strategy

All list queries must be fast. Create these Firestore indexes in the console or `firestore.indexes.json`:

```json
{
  "indexes": [
    {
      "collectionGroup": "transactions",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "date", "order": "DESCENDING" }
      ]
    },
    {
      "collectionGroup": "transactions",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "type", "order": "ASCENDING" },
        { "fieldPath": "date", "order": "DESCENDING" }
      ]
    },
    {
      "collectionGroup": "transactions",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "categoryId", "order": "ASCENDING" },
        { "fieldPath": "date", "order": "DESCENDING" }
      ]
    },
    {
      "collectionGroup": "transactions",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "accountId", "order": "ASCENDING" },
        { "fieldPath": "date", "order": "DESCENDING" }
      ]
    },
    {
      "collectionGroup": "recurringRules",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "isActive", "order": "ASCENDING" },
        { "fieldPath": "nextDue", "order": "ASCENDING" }
      ]
    },
    {
      "collectionGroup": "notifications",
      "queryScope": "COLLECTION",
      "fields": [
        { "fieldPath": "isRead", "order": "ASCENDING" },
        { "fieldPath": "createdAt", "order": "DESCENDING" }
      ]
    }
  ]
}
```
